# COSYlanguages Design System - Assets & Imagery Guidelines

## 1. Icon System
- **Library Recommendation:** Phosphor Icons / Heroicons (SVG format).
- **Standard Scale:**
  - `sm`: 16px
  - `md`: 20px
  - `lg`: 24px
  - `xl`: 32px
- **Stroke Width:** Consistent 2px vector outline.
- **Coloring:** Inherits `currentColor` from text context unless specifying functional state colors (e.g., success green, error red).

## 2. Imagery & Photography
- **Style:** Bright, friendly, accessible educational aesthetics with soft lighting and natural environments.
- **Aspect Ratios:**
  - Cards / Thumbnails: `16:9` or `4:3`
  - Hero Backgrounds: `21:9`
  - Character Portraits: `1:1`
- **Border Radius:** `8px` or `12px` (`var(--cosy-radius-md)`).

## 3. Logo Usage
- **Primary Logo:** COSY World Globe SVG with bold typography.
- **Clear Space:** Maintain minimum clear padding equal to the height of the globe icon on all sides.
- **Do Not:** Stretch, recolor with non-system hexes, or obscure background contrast.
